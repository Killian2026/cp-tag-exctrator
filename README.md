# CPTE
基于标签嵌入的算法竞赛题重复检测系统。

> ⚠️ **当前状态：MVP（最小可行产品）**
> 
> 本项目目前处于早期开发阶段，核心功能已实现但还需要大量改进和迭代。欢迎反馈和建议！

本项目旨在解决算法竞赛中的"重题"问题——即比赛中出现与已有题目相同或高度相似的题目，导致比赛不公平。通过大语言模型（LLM）提取题目的算法标签，再使用神经网络将标签嵌入为稠密向量进行相似度检索，从而高效识别重复题目。

## 快速部署
`LLM.py` 中，需要更改 `call_AI()` 函数，设置可用的模型提供商，建议使用 `deepseek-v4-flash`。  
在 `problems/` 中加入 `.md` 的题目，只要题面。  
调用 `batch_add.py` 批量从 `problems/` 加题。  
使用 `python main.py < problem.txt` 进行检索。  

## 项目结构
``````
TagDict.py         标签字典
batch_add.py       批量加题
db.py              数据库
main.py            检索主函数
tag_embedding.pt   神经网络权重
tool.py            工具：数据库管理
dataset.py         工具：标签集处理
differ.py          工具：集合相似度，已弃用
model.py           工具：神经网络
``````

## 项目优势
- ✅ 可解释性强：流程透明，标签可追溯
- ✅ 扩展性高：支持标签搜题、辅助训练等扩展功能
- ✅ 准确率高：相比传统嵌入方法，能更自然地剔除题目故事
- ✅ 本地化部署：支持离线运行

本地部署可能需要较大的语言模型，建议使用云端 API，`deepseek-v4-flash` 表现卓越。
