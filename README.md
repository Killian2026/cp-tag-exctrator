# CPTE
基于标签嵌入的算法竞赛题重复检测系统。

> ⚠️ **当前状态：MVP（最小可行产品）**
> 
> 本项目目前处于早期开发阶段，核心功能已实现但还需要大量改进和迭代。欢迎反馈和建议！

本项目旨在解决算法竞赛中的"重题"问题——即比赛中出现与已有题目相同或高度相似的题目，导致比赛不公平。通过大语言模型（LLM）提取题目的算法标签，再使用神经网络将标签嵌入为稠密向量进行相似度检索，从而高效识别重复题目。

## 项目优势
- ✅ 可解释性强：流程透明，标签可追溯
- ✅ 扩展性高：支持标签搜题、辅助训练等扩展功能
- ✅ 准确率高：相比传统嵌入方法，能更自然地剔除题目故事
- ✅ 本地化部署：支持离线运行*

本地部署可能需要较大的语言模型，建议使用云端 API，`deepseek-v4-flash` 表现卓越。
